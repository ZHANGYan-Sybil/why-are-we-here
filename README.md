# Why Are We Here?

## Introduction
In the era of AI code generation, artificial intelligence can produce functional programming code from simple natural language prompts. However, learning programming is still irreplaceable for designers and artists. Programming literacy enables creators to deliver precise prompts, detect hidden errors in AI outputs, and define core creative logic that AI cannot invent.

### Precise Creative Control Depends on Code Understanding
Without understanding programming logic, designers can only use vague prompts and passively accept random AI results. Mastering code parameters allows creators to precisely control visual chaos, adjust details, and turn abstract ideas into accurate computational expressions.
> Case: Schotter generative art

### Programming Literacy Enables Critical Judgment of AI Output
AI often produces syntactically correct but logically flawed code that runs without crashing. Only designers with code knowledge can identify invisible logical faults, distinguish valid output from misleading results, and avoid blindly trusting automated generation.
> Case: 3×5 grid hidden reference fault

### AI Executes Logic, While Humans Define Creative Logic
AI is a powerful execution tool for coding and rendering, but it cannot independently form creative concepts or data storytelling frameworks. In computational art, human designers determine datasets, visual metaphors, structural rules, and interactive logic before AI writes any code.
> Case: Tidal stream concentric ring visualisation

## Conclusion
Learning programming in the age of AI is not about manually writing every line of code. It empowers designers to control media precisely, judge AI outputs critically, and retain authorship of computational creative work.
